# Ошибки сборки из IDE

Сюда человек вставляет сообщения CODESYS, которые нужно разобрать: ошибки импорта, компиляции,
загрузки в рантайм. По ним исправляются исходники в `src/` или скрипты в `tools/codesys/`.
После исправления запись не удаляется — ставится отметка «исправлено» и ссылка на коммит.

## Как скопировать сообщения

1. В CODESYS открыть окно «Сообщения» (View → Messages), выбрать категорию «Сборка» (Build).
2. Выделить строки (Ctrl+A) и скопировать (Ctrl+C) — копируются серьёзность, описание, проект,
   объект и позиция.
3. Вставить в блок `text` ниже без правок. Не сокращать: номер строки и объект нужны для поиска.
4. Заполнить шапку записи: дата, версия CODESYS, что делали.

## Формат записи

````markdown
### ГГГГ-ММ-ДД — <импорт | сборка | логин/загрузка | тесты> — CODESYS 3.5.17.30

- Действие: <что делали: команда скрипта или пункт меню>
- Коммит: <git rev-parse --short HEAD>
- Статус: открыто | исправлено в <коммит>

```text
<сообщения из окна «Сообщения» как есть>
```

Комментарий: <необязательно: что уже пробовали>
````

в IDE (Менеджер библиотек → «Детали» у зависимостей coUnit и устройства). Предупреждение C0100 о CBML в
сборках с ошибками упомянуто в [ASSUMPTIONS.md](ASSUMPTIONS.md) (D10).
